# 06. Бот в @BotFather

Mini App живёт на любом HTTPS-адресе, но открыть её внутри Telegram можно
только через бота. Бот создаётся за пару минут, код для этого писать не нужно.

## 1. Создать бота

1. Открыть в Telegram [@BotFather](https://t.me/BotFather).
2. Отправить `/newbot`.
3. Ввести имя (видно в чате) — например, `Мята — запись`.
4. Ввести username — латиница, оканчивается на `bot`: например,
   `myata_studio_bot`.
5. BotFather пришлёт **токен**. Для «Мяты» он не нужен (у неё нет сервера), но
   сохраните его в надёжном месте и никому не показывайте — см. главу 05.

## 2. Кнопка меню — самый простой способ

1. В @BotFather: `/mybots` → выбрать бота → **Bot Settings** → **Menu Button**
   → **Configure menu button**.
2. Прислать URL: `https://dmitriy9427.github.io/myata/`
3. Прислать текст кнопки: `Записаться`.

Теперь в чате с ботом слева от поля ввода — кнопка «Записаться», и она
открывает приложение.

> В новых версиях BotFather есть и веб-интерфейс (кнопка **Open** в его
> чате) — там те же настройки в разделе бота.

## 3. Ссылка t.me/… — через /newapp (по желанию)

Чтобы делиться прямой ссылкой на приложение:

1. `/newapp` → выбрать бота.
2. Название, описание, картинка 640×360 (можно взять `public/og.jpg`,
   уменьшив), GIF — можно пропустить (`/empty`).
3. URL: `https://dmitriy9427.github.io/myata/`
4. Короткое имя: например, `book`.

Ссылка: `https://t.me/myata_studio_bot/book`. Её можно вставить в резюме или
отправить кому угодно — откроется сразу приложение.

## 4. Описание бота

`/setdescription` — текст, который видит человек до нажатия «Start»:

```
Онлайн-запись в студию «Мята»: выберите услугу, мастера и время — всё внутри Telegram.
Учебный проект, записи хранятся только у вас.
```

`/setuserpic` — аватарка (можно `public/favicon.svg`, переведённый в PNG).

## Проверка

Открыть бота → кнопка меню. Должно быть видно:

- цвета вашей темы Telegram, а не мятный фон;
- снизу синяя (или вашего цвета) кнопка Telegram «Выбрать время», а не
  кнопка страницы;
- на внутренних экранах — стрелка «назад» в шапке Telegram;
- вибрация при выборе даты и времени (на телефоне);
- запись, сделанная на телефоне, видна в Telegram Desktop — это CloudStorage.

Если видна демо-шапка «Демо вне Telegram» — значит, `initData` пустая:
приложение открыто не через бота (например, ссылкой в обычном браузере).
