## С чего начать

1. Запустить `npm install && npm run dev` и открыть http://localhost:5193 —
   это демо-режим, кнопки Telegram заменены обычными.
2. Прочитать главы 01–03 и открыть `src/telegram/` — там вся связь с Telegram.
3. Поменять что-нибудь маленькое: добавить услугу в `src/data/studio.ts`,
   изменить шаг сетки (`STEP` в `src/lib/schedule.ts`) — и посмотреть, что
   изменится.
4. Создать своего бота по главе 06 и открыть приложение у себя в Telegram.
