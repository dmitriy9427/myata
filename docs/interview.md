# Шпаргалка к собеседованию: «Мята»

## Telegram Mini Apps

**Что такое Telegram Mini App?**
Обычное веб-приложение, которое Telegram открывает во встроенном WebView.
Связь с Telegram — через объект `window.Telegram.WebApp` из скрипта
`telegram-web-app.js`: тема, нативные кнопки, вибрация, облачное хранилище,
данные пользователя.

**Как понять, что приложение открыто в Telegram?**
`WebApp.initData` не пустая. Сам объект `WebApp` есть и в браузере, если
подключён скрипт, — проверять наличие объекта недостаточно.

**Можно ли доверять `initDataUnsafe.user.id`?**
Нет. Это данные на клиенте, их можно подменить. Доверять можно только
`initData`, проверенной на сервере: HMAC-SHA256 с ключом, полученным из токена
бота, плюс проверка свежести `auth_date`.

**Где хранить токен бота?**
Только на сервере. Всё, что попадает в сборку фронтенда (включая `VITE_*`),
видно любому.

**Как сделать, чтобы приложение выглядело «родным»?**
Цвета из CSS-переменных `--tg-theme-*` (Telegram выставляет их сам), главная
кнопка — `MainButton`, «назад» — `BackButton`, вибрация — `HapticFeedback`,
диалоги — `showConfirm`/`showAlert`.

**Что делать со старыми клиентами Telegram?**
Проверять `isVersionAtLeast` перед вызовом новых методов и иметь запасной
вариант. В проекте это одна функция `supports()`.

**Что такое CloudStorage и его ограничения?**
Ключ-значение у пользователя в облаке Telegram, своё для каждого бота.
Значение до 4096 символов, ключ до 128, до 1024 ключей. Не замена базе: пишет
клиент, данные видит только сам пользователь.

## React

**Как связать императивный API (кнопку Telegram) с React?**
Хук с `useEffect`: при монтировании — `show()` и `onClick`, в уборке —
`offClick` и `hide()`. Без отписки обработчики копятся.

**Зачем колбэк кладётся в `useRef`?**
Чтобы подписка была одна, а вызывалась всегда свежая функция с актуальным
замыканием. Иначе пришлось бы переподписываться на каждый рендер (паттерн
«latest ref», будущий `useEffectEvent`).

**Почему MemoryRouter?**
Hash занят параметрами запуска Telegram (`#tgWebAppData=…`), а GitHub Pages не
умеет отдавать `index.html` на любой путь. Ссылки на внутренние экраны в Mini
App не нужны.

**Как сбросить историю MemoryRouter?**
Поменять `key` — React создаст новый роутер с новыми `initialEntries`. Это
общий приём для сброса состояния компонента.

**Почему в `useEffect` нельзя писать `() => obj.method()`?**
Стрелка без скобок возвращает значение, React примет его за функцию уборки и
упадёт с «destroy is not a function».

## Логика и архитектура

**Как проверить пересечение двух интервалов?**
`a.from < b.to && b.from < a.to` для полуинтервалов `[from, to)`.

**Зачем генератор случайных чисел с зерном?**
Чтобы демо-данные были одинаковыми при каждом открытии. `Math.random()` зерна
не имеет; mulberry32 + хеш строки дают стабильную последовательность.

**Почему время в функциях расписания — параметр `now`?**
Чистые функции: результат зависит только от аргументов, тесты не зависят от
текущего времени, линтер не ругается на нечистый рендер.

**Оптимистичное обновление или «сначала сохранить»?**
Зависит от цены ошибки. Лайк — оптимистично. Запись к мастеру или оплата —
сначала сохранить, иначе пользователь увидит подтверждение того, чего нет.

**Почему данные из хранилища валидируются?**
Хранилище — граница доверия: туда могла записать старая версия приложения или
сам пользователь. Битые записи отбрасываются, приложение не падает.

**Что нужно, чтобы сделать из демо настоящий продукт?**
Сервер с проверкой `initData`, общая база записей с уникальностью «мастер +
время», уведомления от бота, админка для студии, оплата через Telegram
Payments/Stars.
