# 01. Что такое Mini App

Mini App (официально — Web App) — **обычный сайт**, который Telegram открывает
внутри себя: в шторке поверх чата или на весь экран. Никакого отдельного SDK
под iOS и Android: HTML, CSS, JS, любой фреймворк. «Мята» — это React + Vite,
собранные в статику и выложенные на GitHub Pages.

## Чем Mini App отличается от сайта в браузере

Telegram открывает страницу во встроенном WebView и даёт ей мост к себе —
объект `window.Telegram.WebApp`:

| Что | Зачем |
| --- | --- |
| `initData` | Кто открыл приложение (подписанная строка, см. главу 05) |
| `themeParams` и CSS-переменные `--tg-theme-*` | Цвета темы пользователя — приложение выглядит «родным» |
| `MainButton` | Большая кнопка внизу экрана Telegram |
| `BackButton` | Стрелка «назад» в шапке Telegram |
| `HapticFeedback` | Вибрация на телефоне |
| `CloudStorage` | Маленькое хранилище «ключ-значение» у пользователя в облаке Telegram |
| `showConfirm`, `showAlert` | Нативные диалоги |
| `expand`, `close`, `enableClosingConfirmation` | Управление окном |

Мост появляется после подключения скрипта — в `index.html`:

```html
<script src="https://telegram.org/js/telegram-web-app.js"></script>
```

Скрипт подключается **обычным тегом без `async`**, до кода приложения: к
моменту запуска React объект уже должен существовать.

## Откуда пользователь открывает приложение

- **Кнопка меню** бота (слева от поля ввода) — самый простой способ.
- **Ссылка** вида `t.me/<бот>/<приложение>` — Mini App, зарегистрированная
  командой `/newapp`.
- Кнопка в сообщении бота (`web_app` в inline-клавиатуре) — нужен свой бэкенд бота.

Как всё это настроить — глава 06.

## Как приложение узнаёт, что оно в Telegram

При открытии Telegram добавляет к адресу hash с параметрами:

```
https://dmitriy9427.github.io/myata/#tgWebAppData=query_id%3D…&tgWebAppVersion=8.0&tgWebAppThemeParams=…
```

Скрипт `telegram-web-app.js` разбирает его и заполняет `WebApp.initData`. В
обычном браузере скрипт тоже создаёт объект, но `initData` пустая. Отсюда
главное правило проекта:

```ts
export const inTelegram = Boolean(tg?.initData)
```

**Следствие:** hash адреса занят Telegram. Поэтому в «Мяте» не HashRouter, а
MemoryRouter — подробнее в главе 04.

## Что такое «версия» клиента

У каждого клиента Telegram своя версия Bot API: `WebApp.version` — `'6.0'`,
`'7.10'`, `'8.0'`… Новые методы появляются в новых версиях: например,
`CloudStorage` — с 6.9, `setHeaderColor` — с 6.1. Старый клиент на телефоне
бабушки бросит ошибку, если вызвать то, чего он не знает. Проверка —
`WebApp.isVersionAtLeast('6.9')`, в проекте она спрятана в `supports()` (глава 02).

## Структура проекта

```
src/
  telegram/        всё про Telegram: типы, обёртка, хуки кнопок, замена кнопок
  data/studio.ts   студия, услуги, мастера (в настоящем проекте — с сервера)
  lib/             чистая логика без React: даты, расписание, записи (+ тесты)
  store/           сторы Zustand: записи, черновик записи, навигация
  screens/         экраны: Home → Book → Confirm → Done, Bookings
  App.tsx          роутер и каркас
  main.tsx         запуск: initTelegram(), класс на <html>
```

Правило слоёв: `lib/` не знает про React и Telegram, `screens/` не знают про
`window.Telegram` — только про обёртку из `telegram/`.

## Ошибки

> **Проверять «в Telegram ли мы» по `window.Telegram`.** Скрипт Telegram создаёт объект и в
> обычном браузере. Признак — непустой `initData`.
>
> **Звать метод, которого нет у старого клиента.** У кого-то Telegram не обновлялся год — метод
> `undefined`, приложение падает. Проверяйте версию (`isVersionAtLeast`).
>
> **Забыть `ready()`.** Telegram показывает заглушку загрузки, пока приложение не скажет «готово».

## Попробуйте сами

1. Откройте демо в обычном браузере. Чем внешне отличается главная кнопка от той, что в Telegram?
2. Откройте консоль в демо и выполните `window.Telegram?.WebApp?.initData`. Что вернётся и почему
   приложение решило, что оно не в Telegram?

<details>
<summary>Ответы</summary>

1. В браузере это обычная кнопка страницы (`FallbackMainButton`); в Telegram — системная кнопка
   клиента под приложением.
2. Пустая строка (или `undefined`): данные о пользователе Telegram передаёт только при открытии
   из Telegram. `inTelegram = Boolean(tg?.initData)` — ложь.
</details>
